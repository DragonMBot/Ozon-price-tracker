ЛОКАЛЬНАЯ ДИАГНОСТИКА

Проверка приложения

Проверки не запускают парсер и не обращаются к Ozon. Для графиков в базу будут добавлены три явно помеченных фиктивных товара с историей цен. Они останутся в базе до ручного удаления.

Для безопасности email должен совпадать с аккаунтом, в который вы вошли. Чтобы подготовить данные для другого аккаунта, запустите scripts/run_checks.py.
